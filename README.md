# nidaesenn.github.io

Personal portfolio — plain HTML/CSS/JS, no build step.

- Edit projects in `assets/projects.js` (title, tags, stats, body, links; `img` for a real image, otherwise `art` picks a generated cover).
- Add a profile photo at `assets/img/profile.jpg` (square works best).
- Replace the resume at `assets/docs/Nida_Esen_Resume.pdf`.
- Preview locally: `python3 -m http.server 8765` then open http://localhost:8765
